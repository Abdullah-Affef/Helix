## ✨ Features

### 🎮 Minecraft Version Management
- Install and launch multiple Minecraft versions
- Vanilla support
- Fabric support
- Automatic game file management
- Easy version switching

### 👤 Account Support
- Offline accounts
- Ely.by authentication
- Multiple account management
- Quick account switching

### 📂 Instance Management
- Create unlimited instances
- Custom instance names
- Profile pictures for instances
- Creation date tracking
- Launch instances independently
- Instances remain functional even after closing the launcher

### 🧩 Modding Support
- Built-in Modrinth integration
- Download mods directly from the launcher
- Install modpacks with one click
- Resource pack management
- Shader pack management
- Search and filtering system

### 🎨 Modern User Interface
- Clean and intuitive design
- Fast navigation
- Dark theme
- Inspired by modern launchers like Helios
- Responsive layout

## 🚀 Installation

### Download

1. Navigate to the Releases page.
2. Download the latest installer.
3. Run the installer.
4. Launch Helix Launcher.

### Build From Source

#### Requirements

- Node.js 20+
- npm
- Git

#### Clone Repository

```bash
git clone https://github.com/yourusername/helix-launcher.git
cd helix-launcher
```

#### Install Dependencies

```bash
npm install
```

#### Start Development Mode

```bash
npm run dev
```

#### Build Production Version

```bash
npm run build
```
